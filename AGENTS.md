# JWC24 project requirements

The owner's direction is to restore the original Japanese channel experience.
Preserve original assets, layouts, Japanese copy, menu meanings, sounds,
animations and native flows. Implement the replacement service behind them.

- Do not introduce placeholder pictures, invented prices/metadata, rewritten
  labels, repurposed menu controls, or replacement screens into the authentic
  experience. Missing original material or unimplemented behavior is unfinished
  work, not permission to invent a substitute.
- Distinguish original channel files, historical captures, third-party
  recreations, and JWC24 implementation code. A cached source URL and checksum
  establish what was fetched; they do not establish Nintendo provenance.
- Do not describe an experience as original or complete based only on working
  transport, familiar graphics, or a third-party archive. Record verified
  evidence and remaining fidelity gaps. Preserve existing experiments while
  recovering originals; do not silently replace functioning flows with errors.
- Current data can be supplied by replacement providers where authorized
  (for example Hot Pepper restaurant data). Never fabricate provider menus,
  orderability, availability, or order confirmation.
- Keep original software, recovered proprietary files, NAND data and device
  credentials private and outside Git. Do not modify the owner's actual Wii
  backup. Only the explicitly authorized isolated vWii test profile may use
  the owner's vWii credentials.
- Commit completed, scoped work and update relevant documentation. Leave
  unrelated worktree changes untouched.
