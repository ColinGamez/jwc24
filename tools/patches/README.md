# Dolphin WC24 source patch

`dolphin_wc24_mail_receive.patch` modifies public Dolphin Emulator source based
on commit `cb9df1264526c37ed3901afc622c456e8ee137da`. The included source retains
its per-file `GPL-2.0-or-later` SPDX identifiers and Dolphin copyright notices.
The matching license text is [included here](LICENSE.dolphin-GPL-2.0-or-later.txt).
The patch is supplied under those source-file terms; it is not Nintendo code.

See [the receive implementation notes](../../channels/mail/dolphin_receive.md)
for application/build instructions, checks and limits. Binary builds, Nintendo
material, device credentials and profiles are outside this directory and Git.
